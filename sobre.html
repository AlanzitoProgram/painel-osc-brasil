Sobre o Painel OSC Brasil

Objetivo

O Painel OSC Brasil foi criado para apresentar dados públicos sobre transferências federais para Organizações da Sociedade Civil de forma clara, neutra e verificável.

Para quem serve

O projeto pode ser usado por estudantes, jornalistas, pesquisadores, gestores públicos e cidadãos interessados em acompanhar dados públicos sem depender de interpretações partidárias.

Tecnologias

A primeira versão usa HTML5, CSS3, JavaScript puro, Chart.js por CDN e arquivos JSON. Ela foi pensada para funcionar no GitHub Pages sem backend ou banco de dados.
